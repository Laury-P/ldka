# 🌐 Site Web HTML/CSS – Projet autodidacte

## 📌 Contexte
Projet réalisé de manière **autodidacte** il y a 3 ans pour m’initier au développement web.  
Objectif : apprendre les bases de **HTML** et **CSS**, structurer une page, créer des formulaires et comprendre le flux d’une page web.

---

## ⚙️ Fonctionnalités
- Pages HTML structurées avec titres, paragraphes, images
- Mise en forme avec CSS (typographie, couleurs, disposition)
- Formulaires présents, mais **non fonctionnels** (pas de back-end)
- Navigation simple entre les pages

---

## 🧠 Ce que ce projet démontre
- Initiative personnelle pour apprendre à coder
- Compréhension des concepts de base du HTML et CSS
- Premiers pas dans l’organisation d’un projet web

---

## 🚀 Limitations
- Les formulaires ne fonctionnent pas (pas de traitement côté serveur)
- Projet historique / éducatif, réalisé avant ma formation Android
- Code volontairement simple pour se concentrer sur les bases

---

## 📎 À propos
Projet à titre pédagogique uniquement, pour **mon apprentissage personnel**.  
Ne reflète pas mes compétences actuelles en développement Android.
